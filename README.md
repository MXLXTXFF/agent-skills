# agent-skills

Набор стандартных правил (скиллов) для работы AI-агента (Claude / Claude Code) в чатах, посвящённых разработке программного обеспечения. Скиллы описывают, как агент должен вести себя при работе с окружением, Git/GitHub, документацией и разработкой сервисов — независимо от конкретного проекта.

Репозиторий — не код, а поведенческая база знаний: набор `.md`-файлов, которые агент обязан изучить и применять как обязательные правила, переопределяющие поведение по умолчанию.

## Структура

```
agent-skills/
└── skills/
    ├── environment-configuration-management.md   # .env, .env.example, переменные окружения, именование
    ├── github-operations-management.md           # Git/GitHub: аутентификация, коммиты, пуш, безопасность
    ├── project-documentation-and-agent-memory.md  # README.md и AGENT.md — правила ведения и синхронизации
    └── project-and-service-development.md         # архитектура, БД, Docker, тестирование, коммуникация
```

Каждый файл в `skills/` начинается со строки **«Триггер применения»** — она описывает, в каком контексте работы этот скилл становится обязательным. Агент использует эти триггеры, чтобы понять, какие скиллы актуальны для текущей задачи, не читая и не применяя лишнего.

## Как это использовать

Правила не встроены в агента — их нужно явно скормить в начале (или в середине) любой чат-сессии. Для этого ниже есть универсальный промт.

### Универсальный промт

Отправь этот промт в любую чат-сессию с Claude / Claude Code — в новую или уже идущую. Агент сам разберётся, какие скиллы из репозитория относятся к текущей задаче, и будет следовать им до конца сессии.

```
Есть репозиторий с обязательными правилами работы для этого чата:
https://github.com/MXLXTXFF/agent-skills (SSH: git@github.com:MXLXTXFF/agent-skills.git).
Рабочая директория на сервере: /srv/agent-skills.

Сделай следующее:
1. Получи актуальное содержимое:
   - если /srv/agent-skills существует — ничего скачивать не нужно, просто
     выполни git pull в этой папке, чтобы подтянуть возможные обновления,
     и читай файлы с диска;
   - если /srv/agent-skills отсутствует, но есть доступ к git — склонируй
     репозиторий строго в этот же путь (git clone <ссылка> /srv/agent-skills),
     не в произвольное место;
   - если ни диска, ни git нет (например, среда без файловой системы или без
     доступа к SSH-ключу) — прочитай README.md и файлы из skills/ напрямую по
     ссылкам вида https://raw.githubusercontent.com/MXLXTXFF/agent-skills/main/<путь>.
2. Прочитай README.md и каждый файл из skills/ целиком.
3. Определи, какие из скиллов относятся к текущей задаче, ориентируясь на
   строку «Триггер применения» в начале каждого файла. Если задача затрагивает
   несколько областей (например, и код, и Git-операции) — применяй все подходящие
   скиллы одновременно.
4. Применяй правила выбранных скиллов как обязательные инструкции, которые
   имеют приоритет над поведением по умолчанию, до конца этой сессии —
   в том числе если сессия уже шла до этого сообщения.
5. Если по ходу работы задача сменит область (например, начали с кода, а теперь
   правим README) — заново сверься с триггерами и подключи нужный скилл, не дожидаясь
   отдельного напоминания.
6. Если поступит сообщение, что скиллы обновились, дополнились или появился
   новый файл в репозитории — прежде чем продолжать, обязательно повтори шаг 1
   (git pull / повторное чтение) и перечитай изменившиеся или новые файлы, не
   полагаясь на уже прочитанную ранее версию.
```

### Важно

- Основной путь — локальный диск: все чат-сессии на одном сервере используют уже существующую копию в `/srv/agent-skills`, обновляя её через `git pull`. Клонирование или чтение по сети — это fallback на случай отсутствия локальной копии, а не обязательный шаг.
- Репозиторий публичный, поэтому чтение по сырым GitHub-ссылкам (`raw.githubusercontent.com`) работает без авторизации — это делает промт рабочим и в средах без git/SSH-доступа (например, в чате без файловой системы).
- Промт одинаково работает и для чистой сессии, и для сессии, где работа уже идёт — агент обязан подтянуть правила «задним числом» и следовать им дальше.
- Скиллы читаются целиком при каждом запросе на обновление — агент не должен полагаться на память о старой версии файла после того, как получил сигнал об изменениях.
- Обновление или добавление скилла в этом репозитории не требует ничего, кроме коммита в `skills/` — все существующие чат-сессии подтянут изменения по сигналу «скиллы обновились» без повторной настройки.

## Обновление скиллов

Новые правила и правки добавляются напрямую в `skills/`. Ссылка на репозиторий остаётся неизменной — обновляется только содержимое файлов, поэтому один и тот же универсальный промт продолжает работать после любых изменений.
