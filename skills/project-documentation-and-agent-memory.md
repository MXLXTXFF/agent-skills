# Project Documentation and Agent Memory

**Триггер применения:** создание или обновление `README.md`, `AGENT.md` и любой другой документации проекта; завершение задачи, затрагивающей структуру, эндпоинты, окружение или статус разработки.

## 1. Публичная документация (README.md)
* **Язык и стиль:** Документ ведется на русском языке в строгом техническом стиле без вводных слов и сленга.
* **Назначение:** Полное руководство для стороннего разработчика или пользователя по развертыванию и пониманию сервиса с нуля.
* **Обязательные секции:**
  * Описание логики и назначения системы.
  * Полный список используемых технологий и инструментов.
  * Пошаговая инструкция запуска в Docker.
  * Дерево директорий с описанием ответственности папок и модулей.
  * Список и описание API-эндпоинтов системы.
  * Секция планирования (RoadMap).
* **Правила ведения RoadMap:** Задачи разделяются на находящиеся в планах и задачи с созданным фундаментом. После полного завершения задачи она удаляется из секции RoadMap.

## 2. Оперативная память нейросети (AGENT.md)
* **Язык и формат:** Документ ведется строго на английском языке в формате с высокой плотностью технической информации.
* **Назначение:** Долгосрочная контекстная память модели для быстрой ориентации в архитектуре и текущем состоянии проекта без считывания всего исходного кода.
* **Содержимое:**
  * Текущий архитектурный контекст и межсервисные связи.
  * Критические технические ограничения и нюансы реализации.
  * Текущий статус разработки и принятые решения.
  * Ссылки на публичную документацию для базовых команд запуска.
* **Оптимизация контекста:** Файл сохраняется максимально компактным и выверяется на отсутствие дублирования текста из публичной документации.

## 3. Правила синхронизации и обновления
* **Единый триггер обновления:** По завершении любой задачи проводится двухэтапная проверка изменений.
* **Проверка README.md:** Документ обновляется, если изменились структура директорий, публичные эндпоинты, параметры запуска, список сервисов или задачи в RoadMap.
* **Проверка AGENT.md:** Документ обновляется, если изменились архитектурные связи, логика взаимодействия компонентов или внутренний статус реализации.
